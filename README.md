My name is Amin. I like watching movies and thinking about transit/housing policy. For work and other technology stuff I like messing with computers.

I spend a lot of time [vibecoding](https://xcancel.com/karpathy/status/1886192184808149383) little tools from the backlog of ideas that I've built up over the years.

I do like AI. I don't think it is inherently bad for humans or the environment, and I don't really believe in [x-risk](https://en.wikipedia.org/wiki/Existential_risk_from_artificial_intelligence). I would like more transparency in the industry, open weights, and so on.

There's also a huge opportunity to *increase* human-to-human interaction through translation tools, along with accessibility gains--[computer-use](https://github.com/trycua/cua) and similar tools for browsers included.

I like making tools that address things like:
- software annoyances
- complex rule or bureaucratic process navigation
- political policy summaries, explanations, and fact-checking/context augmentation
- import, export, archiving, preservation, duplicate-checking (almost anything that fits in the [DataHoarder](https://www.reddit.com/r/DataHoarder/) universe)
- RAG and sourced, semantic search with language models
